# Legacy lab coexistence boundary

The existing compatibility lab remains intact until the new Kodi Lab creates
and validates its first replacement runtime and retirement is separately
authorized.

Protected components include existing Kodi containers, profiles, images,
networks, browser publications, service state, `<legacy-lab-root>`, and
`<preservation-archive>`. The exact host inventory remains private operational
evidence.

New code must not reuse legacy runtime-directory, service, container, or network
names during coexistence. Before live work, check the private host inventory
for port, network, path, profile, and preservation conflicts.
