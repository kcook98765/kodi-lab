Agents

Connect an MCP-compatible agent to Kodi. An MCP client is the set of permissions and sign-in tokens for one agent; it is separate from your Web administrator account.

1. Create or select a client

Use a separate client for each agent. If you already have one, open it in Your clients below.

Production Inspection is for read-only health, add-on and UI-state inspection. Choose Production Visual Inspection if you also need screenshots. Neither preset grants Kodi control or development access.

2. Give access and connect your agent

  1. Open your client below and grant access to the specific Kodi you want it to inspect. Follow the Kodi access instructions in that client.
  2. Choose a token lifetime and select Issue token. Copy the token immediately: it is shown once and cannot be recovered after navigation or reload.
  3. Use the settings below in your agent's MCP server configuration. Replace the token placeholder in the agent's protected local settings, never in command arguments. Your agent may require a server name or an outer configuration wrapper.
  4. Connect the agent, then ask it to list available Kodi instances and inspect your Kodi's health or UI state. If you chose visual inspection, try a screenshot. If access is denied, check the client preset and that Kodi's grants and current scopes below.

The kodi-lab-mcp-stdio command must be installed where your agent runs. Its connection must reach Kodi Lab at a local 127.0.0.1 or localhost address on that computer. An agent on another computer needs an existing local forwarding arrangement; a LAN Web address is not supported by this command.

Configuration template

This uses the default local port 8100. Replace it with your Kodi Lab Web port if different (for example, 18100). This template contains a placeholder, not an issued token.

{
  "command": "kodi-lab-mcp-stdio",
  "args": [],
  "env": {
    "KODI_LAB_MCP_TOKEN": "PASTE_NEW_TOKEN_HERE",
    "KODI_LAB_MCP_URL": "http://127.0.0.1:8100/mcp"
  }
}

You can also select and copy the template manually. Protect the local settings containing your token as you would a password.

Kodi access

Creating a client or issuing a token does not grant access to Kodi. The client preset and the Kodi policy must both allow the requested inspection.

For Home Kodi, use Grant, then Grant current inspect scope for that Kodi. For screenshots, also use Grant current visual scope when available. These are separate, explicit permissions. If the required control is missing, review this client's preset and the Kodi policy under Advanced administration.
