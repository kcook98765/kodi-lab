Install Kodi Lab Bridge

Follow these steps on Kodi before entering a pairing code below. The same Bridge works for Home and Development Kodi.

{% if repository_source_url %}

Use this URL in Kodi's File manager.

{% else %}

The Kodi Lab repository source URL is not configured. Ask your administrator to check Kodi repository settings before installing.

{% endif %}
  1. In Kodi, open Settings → File manager → Add source.
  2. Enter the Kodi Lab repository source URL shown above.
  3. Name the source Kodi Lab and select OK.
  4. Open Kodi Add-ons.
  5. Select the package / open-box icon.
  6. Select Install from zip file. If prompted, enable Unknown sources in Settings → System → Add-ons, then return to Install from zip file.
  7. Select the Kodi Lab source.
  8. Install {{ repository_zip_name|default('repository.kodi-lab-1.0.0.zip') }}. This installs the repository.
  9. Open Install from repository → Kodi Lab.
  10. Under Services, install Kodi Lab Bridge. Kodi currently lists it as Kodi Lab Narrow Bridge.
  11. Open Add-ons → My add-ons → Services → Kodi Lab Narrow Bridge. Enable the add-on if needed, then open Configure and turn on Enable bridge. Save the settings and restart Kodi locally so the service starts.
  12. Return to the Bridge's Configure screen and choose Pair Kodi Lab to see the four-character code. If no code is active, choose Generate new code. Enter the code on this page before it expires after five minutes.

Kodi Lab Bridge is installed through the Kodi Lab repository.

Compatible official Bridge releases from the Kodi Lab repository are recognized automatically. No separate build approval is needed.

Kodi web interface

In Settings → Services → Control, turn on Allow remote control via HTTP. Use port 8080, or enter your configured port in Advanced connection details (Home) or Advanced ports (Development) below. This also provides Kodi's JSON-RPC connection.

Keep Require authentication enabled where available and set a Kodi username and password. Enter those same credentials in this page's Kodi sign-in fields. For a Kodi already configured without authentication, leave the fields empty.

Keep Kodi and Kodi Lab on a trusted private network. The Kodi Lab server must be able to reach Kodi's web port and Bridge port (normally 8765); Kodi must be able to reach the repository URL. If settings are hidden, change Kodi's settings level to Standard or higher.
