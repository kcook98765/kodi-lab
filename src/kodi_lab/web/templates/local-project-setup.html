Set up local add-on projects

An administrator chooses one directory containing the local projects Kodi Lab may read. No directory is selected automatically.

  1. Choose an existing directory on the Kodi Lab host. It and its parent directories must be real directories, with read and traverse access for Kodi Lab.
  2. For a bundle installation, follow local development source setup to configure the directory and enable the existing development Compose overlay for both Web and broker. For a source installation, set KODI_LAB_DEVELOPMENT_ROOT for both services.
  3. In Agents, create or choose an enabled development client with workspace inspection/editing permissions. Each project selection approves only that client and project.
  4. Return to Current Managed Kodi, select your add-on project, then choose Kodi.

A project can contain addon.xml directly, or one immediate installable add-on subdirectory. For a repository with multiple add-ons, select the installable subdirectory explicitly. Symlinks and paths outside the approved root are rejected.
