Reset Kodi?

      
Reset permanently discards this version’s Kodi settings, installed add-ons and profile data. Independent development source, workspaces, Git history and retained Lab evidence are preserved.

      
The replacement will be clean and stopped. Previous Bridge trust and deployment baselines will need fresh setup.
